# Lucas Veronezi CRM

Projeto do site imobiliário + CRM de Lucas Veronezi.

## Etapa atual
Base inicial versionada no GitHub para evolução para a versão online com banco de dados, autenticação e armazenamento de fotos.

## Próximas etapas
- separar a aplicação em estrutura de produção;
- configurar banco de dados e autenticação;
- implementar agenda real baseada em datas;
- persistir clientes, repescagem, imóveis e tarefas online;
- armazenamento e ordenação de fotos;
- publicação da Landing Page e área administrativa.

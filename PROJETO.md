# Diretrizes do projeto

- Landing Page pública + CRM privado.
- Imóveis apenas para venda.
- Identidade visual: azul-marinho, dourado e branco.
- Todos os cadastros devem possuir Editar.
- Clientes nunca são apagados; perdidos/inativos vão para Repescagem.
- Filtros de tipo e quartos devem ser dinâmicos, derivados do estoque publicado.
- Cadastro de imóvel uma vez, com edição posterior e publicação/despublicação.
- Ordem manual das fotos é preservada na Landing Page e no PDF; foto 1 é a capa.
- Agenda final deve usar datas reais e manter histórico de longo prazo.
- Backend final deve usar autenticação e banco online; localStorage é apenas provisório na base visual.
